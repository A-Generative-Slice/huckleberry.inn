## 📖 Brand Identity & Scraped Visual System

From detailed analysis of **@huckleberry.inn**'s visual assets:
- **Brand Archetype**: French Haute Pâtisserie meets contemporary coquette luxury.
- **Brand Motto**: *“Made to be admired. Made to be savoured slowly.”*
- **Aesthetic Principles**:
  - Architectural French arch frames and botanical woodcut monograms.
  - Fine hairline rules with classical typography.
  - Soothing color palette: Warm antique linen (`#FAF7F2`), deep wine bordeaux (`#4A1420`), muted petal blush (`#F8ECE9`), and warm antique gold (`#C29557`).
  - Strict zero-clutter philosophy with bespoke feather-weight SVG iconography.

## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/A-Generative-Slice/huckleberry.inn.git
cd huckleberry.inn

# Serve with any static server
python3 -m http.server 3000
```

Visit `http://localhost:3000` in your browser.
