## 🌟 Key Features

1. **Interactive Custom Cake Tier & Flavor Builder**:
   - **Tiers**: Miniature Couture Box (Set of 4), 1-Tier Petite (1.0 kg), 2-Tier Grand Milestone (2.5 kg), 3-Tier Regal Banquet (4.5 kg).
   - **Signatures**: Belgian Dark Chocolate Ganache, Persian Lychee Rose & Raspberry, Burnt Basque Cheesecake, Lotus Biscoff Caramel, Sicilian Lemon Wild Berry, Red Velvet.
   - **Artisanal Finishes**: Vintage Lambeth Ruffle Piping, Modern Textured Palette Knife, Velvet Cocoa & 24K Gold Leaf, Semi-Naked Rustic Floral.
   - **Chennai Localized**: 100% Eggless recipe toggle, Shafee Mohammed Rd kitchen pickup, delivery zones (Thousand Lights, Nungambakkam, Alwarpet, Adyar, OMR).

2. **Real-time Dynamic Cake Visualizer**:
   - Live visual cake canvas that dynamically alters frosting colors, tiered structure, and custom piped inscription plaques in real time.

3. **1-Tap WhatsApp Kitchen Dispatch (`wa.me/918511839668`)**:
   - Packages order specifications into a structured token (`#HK-9412`), calculating a 50% advance deposit to secure the baking slot.

4. **Signature Menu & Miniature Couture Showcase**:
   - Filterable gallery showcasing Huckleberry Inn's famed *Miniature Couture* series, Basque cheesecakes, and savouries with 1-click customization.

5. **B2B Kitchen Operations & DM Recovery Simulator**:
   - Interactive slide-up drawer demonstrating how incoming customer inquiries populate the kitchen queue without getting buried in Instagram DMs.

## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/A-Generative-Slice/huckleberry.inn.git
cd huckleberry.inn

# Serve with any static server
python3 -m http.server 3000
# or
npx serve .
```

Visit `http://localhost:3000` in your browser.
