- **Brand Motto**: *“Made to be admired. Made to be savoured slowly.”*

  - Architectural French arch frames and classical typography.

## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/A-Generative-Slice/huckleberry.inn.git
cd huckleberry.inn

# Serve with any static web server
python3 -m http.server 3000
# or with npx
npx serve .
```

Visit `http://localhost:3000` in your web browser.
